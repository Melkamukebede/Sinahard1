---

## 📌 Capstone Project Overview

- **Project Title:** SinaHard National Examination Preparation & Assessment Portal
- **Domain:** Educational Technology (EdTech) / National Curriculum Assessment
- **Target Audience:** Grade 11 & 12 Ethiopian secondary school students, STEM & Social Science educators, and academic administrators.
- **Problem Solved:** Tackling the national educational crisis in Ethiopian secondary education (ESLCE/ESSLCE pass rate disparities) by providing localized, offline-resilient, AI-assisted, and Birr-monetized exam simulation.

## 🌟 Key Features & Innovations

### 1. Ethiopian Localized Fintech Integration
- **Direct Telebirr Developer Gateway**: Native integration supporting RSA signature validation and out-of-band trade number polling.
- **Chapa Payment Gateway**: Seamless mobile checkout for Telebirr and CBE Birr in Ethiopian Birr (ETB).
- **Manual CBE & Bank Transfer Proof**: Direct receipt verification for students without mobile money wallets.

### 2. KaTeX Mobile Phone LaTeX Math Optimizer
- High-level mathematical, physical, and chemical formulas are parsed with customized split-line formatting to ensure **zero horizontal clipping** on standard mobile phone displays.

### 3. AI-Assisted Exam Generation with Human-in-the-Loop
- Powered by Google Gemini (`@google/genai` models) with multi-model fallbacks (`gemini-2.5-flash`, `gemini-2.0-flash`, `gemini-1.5-flash`).
- Questions generated by AI are locked into teacher review pipelines before publication into the official student bank.

### 4. Role-Based Access Control (RBAC) & Security Hardening
- **Students**: Practice exams, track personal historical attempts, review step-by-step explanations, and purchase subscriptions.
- **Teachers**: Author questions, import exams via text or AI assistance, and manage classroom assessments. Must be verified by administrators.
- **Administrators**: Complete oversight over pending student payments, teacher credential verification, real-time analytics, and automated notification controls.

### 5. Automated Transactional Notifications & 1-Click Verification
- Automated email alerts delivered to administrators via Resend/SendGrid or Cloudflare edge runtime whenever a payment is made or an educator registers.
- **1-Click Deep Links**: Admin verification buttons jump straight to the targeted student or teacher record with smooth auto-scroll and blue highlight.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn
- Firebase Project with Firestore enabled

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/sinahard.git
   cd sinahard
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment Variables:**
   Copy `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```
   Provide your Firebase keys, Gemini API key, and optional Chapa/Telebirr credentials.

4. **Run Development Server:**
   ```bash
   npm run dev
   ```
   The application runs on `http://localhost:3000`.

5. **Build for Production:**
   ```bash
   npm run build
   ```
